Gandi

Read from Gandi's own public pages on 25 Nov 2026. https://www.gandi.net/

API

API details for Gandi
APIyes source
Docshttps://api.gandi.net/docs/domains/ source
Auth styleAuthorization: Bearer personal access token (pat_...). Older Apikey scheme still works but is deprecated. source
Sandboxyes (separate sandbox account and key; base https://api.sandbox.gandi.net/v5/; only .com, .net, .org, .fr; transfer not available; Domain, LiveDNS, Billing, Organization, Mailbox APIs). Also a Dry-Run: 1 header on register. source
Registeryes (POST /v5/domain/domains; availability GET /v5/domain/check) source
Transfer inReseller page says the API supports transfers; I did not see a transfer-in endpoint in the portions of the docs read. Availability check can price a transfer process. source
Renewyes (renew path /v5/domain/domains/{domain}/renew per search extract; autorenew PATCH endpoint seen in docs) source
Manage DNSyes via the LiveDNS API (separate doc section) source
Set nameserversSet at registration; a dedicated update endpoint not confirmed in text read. Enabling LiveDNS applies LiveDNS nameservers via POST /v5/domain/domains/{domain}/livedns. source
OtherDNSSEC key endpoints (dnskeys list/add/replace/delete) and LiveDNS DNSSEC activation endpoint. Rate limit 1000 requests per minute per IP (per sandbox guide). source

Extensions

Extension support for Gandi
.ukyes (.uk and .co.uk) source (address no longer resolves, 404 on 25 Nov 2026; check by hand)

Open to anyone, no local presence stated. Personal data protected at registry level for .uk.

.euyes source

Eligible: individuals residing in EU, Norway, Iceland, Liechtenstein; EU citizens; businesses based there. Auth code valid 40 days.

.ptyes source

Anyone can register. No accented names. Auth code valid 30 days, single use. Renew no later than 2 days before expiry. Owner change via customer service only. 30-day deletion quarantine.

Privacy, security and the rest

Other details for Gandi
Pricing modelmargin (published retail prices, with promotions; reseller volume discounts exist) source
WHOIS privacyFree and on by default. For some extensions (.fr, .de, .uk, .nz, .ru) data is protected at registry level and Gandi shows registry-provided WHOIS; email anonymisation does not apply to some extensions including .uk. source
DNSSECSupported. With LiveDNS nameservers, activation is automatic from the Nameservers tab ('Go to DNSSEC'), including DS handling at the registry; with external nameservers you submit the public key manually. ALIAS record on the bare domain breaks DNSSEC. API also exposes dnskeys and LiveDNS DNSSEC activation. Docs pages are old; check live panel. source
Account securitynot stated
Bulk and resellerFree reseller account, no commitment; API for domain creation, renewal, transfers, contacts and DNS; lower rates with higher sales volume (no figures published). Bulk transfer docs exist. source
Other notesSome extensions require a Gandi Corporate Services subscription. Late renewal and restore fees are listed per TLD. Gandi is also the registrar associate behind some Route 53 domains. source

Flags: conflicts or doubts

  • Gandi .pt page showed renewal 'from EUR 30.00' but also EUR 40.00 for a 1-year line; I could not tell which applies to a single year.
  • The all-TLD price table page only covered .abogado to .az so individual TLD pages were used.
  • Transfer and nameserver-update endpoints were not visible in the parts of the API docs read; the reseller page nonetheless claims transfers via the API.
  • Gandi DNSSEC, 2FA docs carry old page metadata (several years); menu labels may differ.
  • Prices were displayed for France and may differ by country or currency selector.
