Privacy, security and the rest

Other details for Cloudflare Registrar
Pricing modelat cost (no markup; registration, transfer and renewal at or below what registries and ICANN charge) source
WHOIS privacyFree personal-data redaction, 'if permitted by the registry'. Whether on by default is not stated on the WHOIS page; the overview says redacted WHOIS is offered by default. Registrant state/country stay visible. source
DNSSECSupported, free, one-click in dashboard. For domains delegated to Cloudflare, Cloudflare publishes CDS/CDNSKEY and Registrar scans them and submits DS to the registry automatically (1 to 2 days). source
Account securitynot stated
Bulk and resellernot stated
whyNo reseller programme found on the pages read. Docs say bulk transfers follow the same process as single ones, each charged individually.
Other notesTransfer-in needs: domain at least 60 days old, no registrant change in 60 days, unlocked, DNSSEC disabled at old registrar, and Cloudflare must be the authoritative DNS (full setup); you cannot use another DNS provider while registered with Cloudflare. Transferred domains locked 60 days. Most gTLD transfers add one year; .uk adds none. Some registrars (Shopify, Block) block nameserver changes so need a workaround. Transfers into Cloudflare are by dashboard; API cannot transfer. source

Flags: conflicts or doubts

  • Cloudflare overview page says over 430 TLDs; developer docs say over 400. Minor wording difference.
  • Docs TLD page defers to the TLD policies page; neither shows .eu or .pt, but absence is not an explicit statement of non-support.
  • WHOIS redaction doc does not say whether it is default; product overview says redacted WHOIS is offered by default.
  • Registrar API is a first beta and may change; per-TLD API support is a subset of dashboard support and not listed on the page read.
