API

API details for Porkbun
APIyes source
Docshttps://porkbun.com/api/json/v3/documentation
Auth styleAPI key and secret key, via X-API-Key and X-Secret-API-Key headers or apikey/secretapikey in the JSON body. Keys work with or without account 2FA. Keys can be restricted by IP (CIDR), domains and permissions. Idempotency-Key and dryRun supported.
Sandboxyes (a pk1_sb_ key runs the API in an isolated environment with fake credit; responses include sandbox: true)
Registeryes (availability/pricing checks up to 25 per call; per-TLD getRegistrationRequirements says whether a TLD is API-registerable)
Transfer inyes (transfer-in listed)
Renewyes
Manage DNSyes (record CRUD, DNSSEC DS records, restore points, URL forwarding)
Set nameserversyes (read or replace nameservers, manage glue records)
OtherSpend cap of USD 100 a month on what keys and agents buy and add as credit until the account holder sets a limit. Webhooks, SSL, email, aftermarket and hosting areas also listed. Exact endpoint paths were not on the page read (OpenAPI spec referenced).

Extensions

Extension support for Porkbun
.ukyes (.uk and .co.uk) source Not read on the official page: from a search summary

Nominet registry terms apply (DRS). No UK presence requirement seen, but Porkbun's general terms mention bona fide business or commercial use clause (generic). Transfer in by setting IPS tag to PORKBUN; no free renewal year on .uk transfer. WHOIS privacy not supported on .uk family. Sources: https://porkbun.com/legal/agreement/registry_conditions and https://kb.porkbun.com/article/180-how-to-transfer-a-uk-domain-to-porkbun (both via search results, not fetched in full).

.euyes (priced on the main table) source

Eligibility rules for .eu not read. Porkbun KB notes .eu registry accepts keyData only for DNSSEC, not dsData.

.ptno (not listed on the pricing page or TLD page) source

Absence from the list, not an explicit statement.

Privacy, security and the rest
