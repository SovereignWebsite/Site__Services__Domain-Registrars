Data and schema

The comparison tables are built from one file you can download and reuse.

registrars.json and its JSON Schema. Checked 25 Nov 2026. 16 registrars.

How the file is shaped

  • Top level: schema_version, title, checked, about and registrars (a list).
  • Every datum is a claim: value (text as the vendor showed it, or null), source (the vendor page it came from), checked (date) and note. A null value means not stated: it could not be sourced from the vendor's own public pages.
  • Per registrar: id, tier (core or extra), name, homepage, api (exists, docs_url, auth_style, sandbox, capabilities, other), tlds (uk, eu, pt), pricing_model, prices (com, uk, eu, pt), whois_privacy, dnssec, account_security, bulk_reseller, other_notes, unverified_flags and sources.
  • A price has first_year, renewal, transfer (strings as displayed), currency, tax_inclusive (true, false or null), reading (how to read it), source and checked. Prices are never converted or rounded, and may be promotional.

Rules

  • Never invent a field: if the vendor's pages do not say, the value stays null.
  • Prices change: each carries the date it was checked and its currency.
  • The tables on this site are generated from this file by docs/build/gen.py in the repository.
